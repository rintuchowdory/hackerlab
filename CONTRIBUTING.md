# Contributing

Thanks for helping improve HackerLab.

1. Keep examples restricted to local/private lab systems.
2. Do not add password spraying, credential theft, persistence, stealth, destructive payloads or public-target bypasses.
3. Add unit tests for parser and target-validation changes.
4. Keep CI limited to static checks and unit tests; do not scan public services in automated workflows.
5. Run `python3 -m unittest discover -s tests -v` before opening a pull request.
