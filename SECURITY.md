# Security Policy

## Supported use

HackerLab is an educational tool for loopback/private lab environments. Do not use it against systems without explicit authorisation.

## Reporting a vulnerability

Please open a private security advisory in the GitHub repository when available. Do not include secrets, personal data, or details that would enable attacks against third-party systems in public issues.

## Scope note

The target validation is defence-in-depth and cannot guarantee that a network is safe. DNS rebinding, proxies, routing, container configuration, redirects and network changes can affect the real destination. Use isolated lab networks and verify scope independently.
