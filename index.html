Safe by design

Authorisation first. Test only systems you own or have explicit written permission to assess. Follow each tool's scope and rate limits.

The Vercel website is a static learning interface. It does not execute scanners, connect to Kali, send pasted content to a server, or host the intentionally vulnerable Juice Shop.
