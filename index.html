Launch your local training environment

Run these commands on your Kali host, from the HackerLab repository directory.

docker compose up -d juice-shop
docker compose build hackerlab
docker compose run --rm hackerlab

Inside the toolbox, use juice-shop as the target hostname. The Compose network is internal-only.

Safety boundary

This hosted dashboard is an information and learning interface. It does not run Nmap, Gobuster or WPScan from Vercel, and it does not connect to your Kali machine.

Keep OWASP Juice Shop private to your Docker lab. Never expose the intentionally vulnerable target to the public internet.
